# Context Map

This repository is a multi-package PHP library monorepo.

- `packages/core/CONTEXT.md` — core structures, equality, optional values, and PHPUnit support.
- `packages/time/CONTEXT.md` — clock abstractions, temporal value objects, and formatting.
- `packages/comparison/CONTEXT.md` — comparison primitives and ordering contracts.

Cross-package architecture decisions belong in `docs/adr/`; package-specific decisions belong in `packages/<package>/docs/adr/`.
